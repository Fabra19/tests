Данный проект был написан в целях изучения метода написания кода через TDD (Test-Driven Development, разработка через тестирование).

Для реализации работы с TDD использовалась внутренняя библиотека unittest.

This project was written to study the method of writing code using TDD (Test-Driven Development).

To implement TDD, the internal unittest library was used.
